## 📊 Метрики успеха (KPIs)

1. **Self-Correction Rate:** Доля случаев, когда агент сам исправляет ошибку сборки без подсказки пользователя (>= 75%)

2. **Edit Success Rate:** Процент правок `edit`, применившихся без ошибок поиска `oldString` (>= 98%)

3. **Token Efficiency:** Сокращение расхода токенов на ход за счёт точечной Repo Map и фильтрации мусора (>= 40%)

4. **Crash Free Rate:** 0 падений процесса при некорректном JSON от модели, битых сетевых пакетах или Ctrl+C
